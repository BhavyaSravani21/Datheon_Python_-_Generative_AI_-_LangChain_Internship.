# Datheon Python, Generative AI & LangChain Internship

This repository contains my internship tasks focused on Python programming, Generative AI, LLM applications, and AI agents.

## 🚀 Projects

### Task 1 — Python & Generative AI
A project demonstrating Python programming and Generative AI concepts.

**Folder:** `Task-1`

### Task 2 — DocuMind: RAG Document Q&A
A Retrieval-Augmented Generation (RAG) application that allows users to ask questions about documents and receive AI-generated answers based on the provided content.

**Folder:** `Task-2-RAG-Document-QA`

**Technologies:** Python, Streamlit, Groq, RAG

### Task 3 — Smart Research Agent
A console-based AI agent that uses tools to search the web, perform calculations, and read local text files to answer user queries.

**Folder:** `Task-3-Smart-Research-Agent`

**Technologies:** Python, Groq, Function Calling, DuckDuckGo Search

### Task 4 — Smart Research Chat UI
A conversational AI application with a Streamlit chat interface, streaming responses, conversation history, and tools for web search, calculations, and local file reading.

**Folder:** `Task-4-Streamlit-Chat-UI`

**Technologies:** Python, Streamlit, Groq, Function Calling, DuckDuckGo Search

## ⚙️ Setup and Usage

Each task has its own folder and may have its own dependencies and setup instructions.

1. Clone the repository:

   ```bash
   git clone https://github.com/BhavyaSravani21/Datheon_Python_-_Generative_AI_-_LangChain_Internship.git
   ```

2. Open the folder for the task you want to run.

3. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Configure the required API key in a local `.env` file if the task needs one. Never upload API keys or `.env` files to GitHub.

5. Follow the task-specific README for the correct run command.

## 🔐 Security

API keys and other secrets are stored locally and should not be committed to the repository.
